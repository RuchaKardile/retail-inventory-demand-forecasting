# Retail Inventory & Demand Forecasting

## Business Problem

Retailers need to maintain enough inventory to meet customer demand without tying up excessive capital in slow-moving products.

This project analyzes retail sales, inventory, ordering, pricing, promotional and seasonal data to identify inventory risks, understand demand patterns, and support better replenishment decisions.

## Objectives

The analysis aims to answer:

1. Which products and categories generate the highest sales?
2. Which products show potential stockout risk?
3. Which products appear overstocked or slow-moving?
4. How do promotions, discounts, seasonality and weather relate to demand?
5. How does actual demand compare with the existing demand forecast?
6. Which products or categories require replenishment attention?
7. Can historical demand be used to develop an independent demand forecast?
